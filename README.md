# 🎮 Jogo da Velha em Java

Este é um projeto simples de **Jogo da Velha** desenvolvido com Java e interface gráfica Swing, utilizando o padrão de arquitetura **MVC (Model-View-Controller)**.

---

## 🧠 Funcionalidades

- Interface gráfica intuitiva com `JFrame` e `JPanel`.
- Alternância entre jogadores `X` e `O`.
- Verificação automática de vitória, empate ou andamento.
- Mensagem com o **tempo decorrido** ao final da partida.
- Botão de "Novo Jogo" para reiniciar a partida.

---

## 📁 Estrutura de Pastas
📦 src/ ┣ ┗ Main.java 📂model/ ┃ ┣ ControleJogo.java ┃ ┗ ControleJogoVelha.java ┣ 📂view/ ┃ ┗ FrmJogoVelha.java 


🛠️ Tecnologias
Java 8+
Swing (GUI)
Padrão MVC
